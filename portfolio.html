AI tools are easy to try. Shipping with them is the hard part. I write the spec, direct the agents, verify everything they produce, and ship what passes. The apps below are the receipts — real software, through App Store review, in real users' hands.

How I work

1. Spec first. Every build starts with a written spec: what it does, what it doesn't, and how I'll know it's done.

2. Direct, don't delegate blindly. Agents build in small, verifiable passes. I set the direction; they do the typing.

3. Verify before it ships. Every build gets a build and test verdict — mine, on real devices — before it goes anywhere near a user.

4. Ship it. App Store review, Google Play, real users, real feedback, next version.

The discipline scales. The same loop — clear specs, agent direction, verification gates, shipping — is how enterprise teams should be running AI agents, and it's how I already work every day.
